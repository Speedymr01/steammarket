# Steam Market Prices

Fetches Steam Community Market prices for registered items, logs them to CSV, and displays a price-trend graph.

## Usage

### Main script

```
steammarketapi.pyw [--graph] [--register] [--unregister] [--no-enter-to-exit]
```

No flags = fetch all registered items, append prices to `steammarketprices.csv`.

| Flag | Description |
|------|-------------|
| `--graph` | Plot price history from CSV and open the image |
| `--register` | Add a new item (steam app + item name + optional buy price) |
| `--unregister` | Remove a registered item and its CSV history |
| `--no-enter-to-exit` | Skip the final "Press Enter" prompt |

### Launcher

```
view_steammarket.py
```

Opens the graph immediately (equivalent to `steammarketapi.pyw --graph --no-enter-to-exit`).

## Features

- Multi-game support — registers items across any Steam app
- Buy price tracking — enter what you paid; the graph shows a break-even line accounting for Steam's 15% fee (5% Valve + 10% game)
- Self-modifying registration — registered items persist directly in the script file (no separate config)
- CSV logging with automatic migration of old/malformed data
- Grid at every penny on the graph, with vertical day-boundary lines at midnight
- Prices fetched in GBP

## Dependencies

- `requests`
- `matplotlib`

Install with:

```
pip install requests matplotlib
```

## File structure

| File | Purpose |
|------|---------|
| `steammarketapi.pyw` | Main tool (`.pyw` = no console window on open) |
| `view_steammarket.py` | Shortcut to open the graph |
| `steammarketprices.csv` | Price history (auto-created) |
| `steammarketprices.png` | Graph output (generated by `--graph`) |
